# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.4.x   | :white_check_mark: |
| < 0.4   | :x:                |

## Reporting a Vulnerability

SkillForge takes the security of agent skills and package execution seriously.

If you discover a security vulnerability or bypass in SkillForge (including the security auditor, AST scanner, or MCP server), please report it responsibly:

1. **Email:** Send details to `gintingism@users.noreply.github.com`.
2. **Details to include:**
   - Description of the vulnerability.
   - Minimal proof-of-concept (PoC) skill package or payload.
   - Expected vs actual behavior.
3. **Response timeline:**
   - Acknowledgment within 48 hours.
   - Triage and mitigation patch within 7 business days.

Please do not open public GitHub issues for undisclosed security vulnerabilities.
