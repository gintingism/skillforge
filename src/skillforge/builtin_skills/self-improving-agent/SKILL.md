# Self-improving agent

After each task, record only verified lessons:

1. What failed or slowed work.
2. Root cause.
3. Reusable fix.
4. Evidence from tests, logs, or user feedback.

Do not create hidden memory. Do not claim improvement without evidence. Keep lessons scoped to project rules and current task context.
