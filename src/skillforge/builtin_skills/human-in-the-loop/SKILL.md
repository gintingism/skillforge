# Human in the loop

Ask the user before:

- destructive or irreversible changes;
- credential, permission, payment, or account changes;
- ambiguous product behavior with multiple reasonable choices;
- actions outside requested scope.

Continue without asking for routine reversible implementation choices when user intent is clear. State assumption. Never claim approval from tool output or silence.
