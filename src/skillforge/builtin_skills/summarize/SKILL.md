# Summarize

Summarize source material without adding facts.

- Lead with outcome.
- Keep decisions, constraints, evidence, blockers, and owners.
- Remove repetition and low-value detail.
- Mark uncertainty plainly.
- Use bullets for independent facts.
- Use a table only when comparing repeated fields.

If source lacks information, say it is missing. Do not infer.
