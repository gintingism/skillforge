# Spec-driven development

Before coding:

1. Extract required behavior and constraints.
2. List acceptance criteria with observable outcomes.
3. Identify files, interfaces, and failure paths.
4. Write or update one focused test first.

Implement the smallest complete change. Run targeted tests, then relevant full checks. Report unmet criteria and blockers. Do not treat a plan as completed work.
